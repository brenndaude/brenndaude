# Brenn Daude

French-American engineer. I build LLM agents that run in production for real businesses, and machine
learning on sensor data. I started on DO-178 certified landing-gear and braking software for the
Airbus A350, which is where I learned to trace every requirement to a test. Moving back to Paris.
